第4章 关键方法

本章阐述桌面敲击事件检测、基于 GCC-PHAT 的双通道时延估计、用户标定驱动的扇区语义映射，以及综合置信度、拒识与输出冷却机制。文中参数取值与本文原型系统实现一致；技术笔记（technical-report、accuracy-analysis）中与早期草稿不一致之处（如标定样本条数和输出策略），以本章及当前实现为准。第5章在给定参数配置下开展实验并对性能进行分析。


4.1 桌面敲击事件检测

4.1.1 预处理与包络表征

对左右声道分别进行带通滤波，抑制与敲击瞬态无关的低频扰动与高频噪声。将左右声道在采样域上融合为单路分析信号（对逐采样点取双通道绝对值的较大者），并对该合成信号进行短时平滑，得到用于峰值定位的包络序列。

4.1.2 峰值检测与双峰候选构造

在包络序列上检测局部极大值作为峰值，并施加最小峰间隔约束以避免同一物理敲击产生重复峰。对相邻峰值按时间顺序两两配对，形成双峰候选。双峰时间间隔须落在允许区间内；区间下界抑制同一瞬态分裂，上界抑制两次独立敲击被误并为同一事件。

4.1.3 多约束质量评价

对每个双峰候选计算质量指标，用于刻画事件是否满足近场敲击与双击结构假设，包括峰值幅度、局部信噪比、近场能量比、瞬态强度、双通道一致性、峰尖锐度、双峰间隔，以及双峰幅度的对称强弱比（不对两次敲击轻重次序作单向假设）。各指标经归一化与加权融合为标量质量分。未通过约束的候选不进入时延估计与扇区判别。

4.2 基于 GCC-PHAT 的双通道时延估计

4.2.1 GCC-PHAT 基本原理

广义互相关–相位变换在频域构造互功率谱并施加相位变换以削弱幅度谱差异对时延估计的主导作用，经逆变换得到广义相关函数；主峰对应滞后量为双通道相对时延。

4.2.2 几何先验与搜索范围限制

设双麦克风间距 d = 0.12 m，声速 c = 343 m/s，则最大理论到达时间差约为 d/c ≈ 0.35 ms。在采样率 fs = 16 kHz 下，最大滞后采样数取

    maxLagSamples = floor((d / c) * fs) = 5，

互相关主峰搜索限制在滞后索引区间 [−maxLagSamples, maxLagSamples] 内，共 11 个整数候选点；超出该范围的峰值不作为候选。

4.2.3 主峰亚采样细化

在离散滞后格点上确定主峰索引后，利用主峰邻近采样进行抛物线插值，得到亚采样精度的滞后估计。

4.2.4 短时片段相关与窗函数

以双峰时间中心为参考，截取 gccEventWindowMs = 70 ms 的左右声道片段参与 GCC 计算。对片段施加 Hann 窗（配置项 gccApplyHannWindow = true）以降低边界不连续引起的谱泄漏。

4.2.5 多子带估计融合与子带一致性约束

通带 100 Hz～4000 Hz 按下述边界划分为三子带：100–1400 Hz、1400–2700 Hz、2700–4000 Hz；子带过窄（宽度小于 gccMinSubBandWidthHz = 80 Hz）则跳过。各子带独立带通与归一化后分别计算 GCC，按各子带峰值强度与主峰突出程度加权融合时延与峰形指标。当子带间时延估计的加权标准差超过 gccLagStddevPenaltyThresholdSamples = 1.2 个采样点时，对融合后的主峰–次峰比施加不低于 gccLagStddevPenaltyFloor = 0.55 因子惩罚，使滞后置信度降低。多子带路径可通过 gccMultiBandEnabled 关闭而退化为单带 GCC。

4.2.6 滞后置信度与 GCC 拒识相关阈值

滞后置信度由 GCC 主峰与次峰比值 peakRatio 经线性映射至 [0,1]，映射斜率由 lagConfidenceMultiplier = 3.2 控制；低于 lowLagConfidenceHint = 0.08 时仅作弱提示。主峰–次峰比低于 minPeakRatio = 1.04 时触发与时延可靠性相关的拒识。

4.3 特征构造与扇区语义映射

4.3.1 特征向量

特征包括：时延 delaySeconds；对数能量比、对数综合峰值比、对数第一峰与第二峰通道峰值比；以及由 GCC 峰形得到的滞后置信度 lagConfidence。

4.3.2 用户标定

用户在上、右、下三扇区分别采集标定样本；每扇区目标条数 calibrationSamplesPerDirection = 12（技术笔记中早期分析曾取每区 6 条，本文原型稳定实现采用 12 条）。仅当质量分不低于标定收录阈值时写入标定集。标定数据持久化为 JSON，启动时加载。

4.3.3 分层判别策略

先判别右侧扇区与非右侧集合；若判定为右侧则输出右侧；否则在上侧与下侧之间二元判别。

4.3.4 统计距离判别与近邻回退

当 statModelEnabled = true 且各类标定样本足以估计各类均值与对角方差（实现中要求各类具备足够样本构建统计模型）时，采用对角协方差假设下的马氏距离形成类别得分；若选中类别相对分布的马氏距离超过 statModelDistanceRejectThreshold = 4.2，则拒识。最优类与次优类归一化得分差小于 statModelMarginReject = 0.10 时亦可触发边界拒识。统计模型不可用时回退为 K 近邻（KNN），K 值由各类样本量平衡确定（实现中上限为 5）。


4.4 综合置信度、拒识与输出冷却

4.4.1 综合置信度

综合置信度为几何/分类置信项 c1、敲击质量归一化项 c2（质量分除以 100 并截断至 [0,1]）、滞后置信项 c3（不低于 lowLagConfidenceHint）的乘积；其中 c1 来自扇区判别得分，c2 来自事件检测质量分，c3 来自 GCC 滞后置信度。

在线判别要求综合置信度不低于 testingConfidenceThreshold = 0.28，且质量分不低于 testingAcceptedQualityScore = 52.0，否则拒识。

4.4.2 拒识规则（与配置对应）

除上述阈值外，还包括：GCC 主峰–次峰比低于 minPeakRatio；分类阶段最优与次优得分间隔过小（统计模型模式下间隔阈值为 statModelMarginReject）；以及右侧门控与分层判定不满足时的阶段拒识等。具体拒识原因由实现输出以便分析。

4.4.3 输出冷却

本文原型系统采用单次高置信触发作为默认输出策略。一次有效敲击事件在通过检测、扇区判别、综合置信度与拒识规则后，即可触发对应扇区指令。为避免一次敲击在连续帧中被重复触发，输出侧设置 testingCooldownMs = 900 ms 的冷却时间；标定样本收录侧设置 calibrationCooldownMs = 900 ms 的冷却时间。


4.5 本章小结

本章给出了敲击检测、GCC-PHAT 及其稳健化实现、标定驱动的扇区映射与分层判别、综合置信度、拒识与输出冷却等形式化描述，并在各节列表中给出与原型一致的关键参数。几何上，16 kHz 采样下最大理论时差约占 5～6 个采样点，互相关搜索取 ±5 个采样点并由亚采样细化；检测与 GCC、分类及决策层的阈值共同构成系统的可靠性边界。第5章将在上述配置下汇报实验方案与性能结果。
